# nlo-hub
NLO player hub for nlo.gg

Shop coin packs charge through Stripe, credit the desk ledger, and enqueue an in-game grant. NLOCoins on the Paper box deposits into NLOP (`season admin balance`) when the claimed IGN is online.

```text
bash /opt/nlo/app/deploy/setup-coin-bridge.sh
bash /opt/nlo/app/deploy/install-nlocoins.sh
```
